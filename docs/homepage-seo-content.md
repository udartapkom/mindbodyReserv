# План усиления главной: SEO и информативность

Ориентир: сейчас на `/` мало секций и почти нет перелинковки на каталог материалов, базу знаний, тарифы и поддержку. Цель — больше полезного текста, внутренних ссылок и разметки без превращения главной в «простыню».

---

## Текущее состояние

| # | Секция | Что даёт | SEO-заметка |
|---|--------|----------|-------------|
| 1 | `TitleAnimate` | Герой, H1 про психологов онлайн | Есть H1; без CTA на контент |
| 2 | `MainText` | Ценностное предложение | Текст без H2 и ссылок |
| 3 | `PriceSection` | Карточки тарифов | H2 есть; не ведёт на `/price` |
| 4 | `AttentionSection` | Дисклеймеры перед покупкой | «Подробнее о тарифах» без ссылки |
| 5 | `We` | Ценности бренда | Слабая перелинковка |
| 6 | `QuestionForm` | Форма + мессенджеры | Не ведёт на `/support` |

**Дыры:** нет превью `/problems` и `/instructions`, нет «как это работает», нет FAQ + JSON-LD, короткий `description` в `layout.tsx`, почти нет внутренних ссылок на ключевые разделы.

Связанный контент уже есть на `/about`, `/price` (сравнение + FAQ), `/problems`, `/instructions` — на главную лучше **выносить превью**, а не копировать страницы целиком.

---

## Принципы

1. Одна секция — одна задача и один H2.
2. Каждая новая секция даёт ≥1 внутреннюю ссылку на живой раздел.
3. Не дублировать полный «О нас» и полную таблицу тарифов.
4. Не выдумывать отзывы, цифры и кейсы без подтверждения.
5. Визуально — в духе текущего сайта (без карточного шума в герое).

---

## Фаза 1 — Быстрый SEO-эффект ✅ приоритет

**Цель:** ключи + перелинковка + сниппеты.

| # | Задача | Где | Результат |
|---|--------|-----|-----------|
| 1.1 | Расширить `metadata` главной / сайта: title + description 150–160 символов с УТП | `layout.tsx` и/или `page.tsx` | Нормальный сниппет в выдаче |
| 1.2 | JSON-LD `Organization` + `WebSite` (+ `SearchAction` опционально) | layout или home | Понимание бренда поисковиком |
| 1.3 | Секция **«С чем помогаем»** — темы (тревога, выгорание, отношения…) → `/problems` или конкретные slug | новый компонент на `/` | Тематические ключи + ссылки |
| 1.4 | Секция **«Готовые решения»** — 3–6 free-материалов с API + CTA «Все решения» | `/` + `problems.getProblems('free')` | Индексация через хаб, discovery |
| 1.5 | Починить ссылки в существующих блоках: «тарифы» → `/price`, форма/поддержка → `/support` | `AttentionSection`, `QuestionForm` | Перелинковка без новых секций |

**Оценка:** 1–2 дня.  
**Риск:** низкий.

---

## Фаза 2 — Информативность и доверие

**Цель:** объяснить продукт и снять частые вопросы.

| # | Задача | Где | Результат |
|---|--------|-----|-----------|
| 2.1 | Секция **«Как это работает»** — 3–4 шага + ссылки на `/login`, `/instructions`, `/support` | `/` | Снижение bounce, ясный сценарий |
| 2.2 | Секция **FAQ** (5–7 вопросов) + JSON-LD `FAQPage` | `/` (часть можно переиспользовать с `/price`) | Расширенные сниппеты |
| 2.3 | Превью **базы знаний** — 3 статьи + «Вся база» → `/instructions` | `/` | Long-tail + внутренние ссылки |
| 2.4 | Короткий тизер **«О нас»** (1 абзац + CTA) → `/about` | `/` | Бренд без дубля всей about-страницы |

**Оценка:** 1–2 дня.  
**Риск:** низкий.

## Фаза 3 — Усиление и полировка

**Цель:** дожать доверие и техдолг SEO.

| # | Задача | Результат |
|---|--------|-----------|
| 3.1 | Open Graph / Twitter description синхронизировать с новым meta | Единый шаринг |
| 3.2 | Sitemap / robots проверить наличие `/problems`, `/instructions` | Полный охват разделов |
| 3.3 | Честные соцдоказательства (если появятся факты: форум, кейсы) — без выдуманных цифр | Доверие |
| 3.4 | A/B порядок секций: решения до или после тарифов | Конверсия vs SEO-текст |

**Оценка:** 0.5–1 день (+ контент по фактам).

---

## Рекомендуемый порядок секций на `/`

```text
1. Hero (TitleAnimate) — без перегруза
2. MainText (чуть усилить H2 при необходимости)
3. С чем помогаем                    ← фаза 1
4. Готовые решения (превью)          ← фаза 1
5. Как это работает                  ← фаза 2
6. Тарифы (PriceSection)
7. Перед покупкой (Attention) + ссылка на /price
8. База знаний (превью)              ← фаза 2
9. FAQ                               ← фаза 2
10. Мы (+ тизер О нас → /about)      ← фаза 2
11. Напишите нам (QuestionForm) + /support
```

Тарифы остаются в середине воронки; контентные блоки — выше, чтобы поисковик и пользователь сразу видели пользу.

---

## Вне скоупа (пока)

- Полноценный блог / новости
- Выдуманные отзывы и рейтинги
- Дублирование всей `/price` comparison table на главной
- Тяжёлый видео-hero без контентной отдачи

---

## Критерий готовности

- С главной есть кликабельные пути в `/problems`, `/instructions`, `/price`, `/about`, `/support`
- В выдаче осмысленный description и (желательно) FAQ rich results
- На `/` есть ≥2 контентных секции с H2 и текстом по темам продукта
- Главная не превратилась в дашборд из карточек: герой по-прежнему один композиционный блок

---

## Рекомендуемый порядок поставки

```text
Спринт 1:  1.1–1.5  (meta, schema, темы, превью solutions, ссылки)
Спринт 2:  2.1–2.4  (how it works, FAQ, instructions, about teaser)
Спринт 3:  3.x      (OG, sitemap, факты, порядок секций)
```
