# План усиления главной: SEO и информативность

Ориентир: сейчас на `/` мало секций и почти нет перелинковки на каталог материалов, базу знаний, тарифы и поддержку. Цель — больше полезного текста, внутренних ссылок и разметки без превращения главной в «простыню».

---

## Принципы

1. Одна секция — одна задача и один H2.
2. Каждая новая секция даёт ≥1 внутреннюю ссылку на живой раздел.
3. Не дублировать полный «О нас» и полную таблицу тарифов.
4. Не выдумывать отзывы, цифры и кейсы без подтверждения.
5. Визуально — в духе текущего сайта (без карточного шума в герое).

## Фаза 1 — Быстрый SEO-эффект ✅ готово

**Цель:** ключи + перелинковка + сниппеты.

| # | Задача | Где | Результат | Статус |
|---|--------|-----|-----------|--------|
| 1.1 | Расширить `metadata`: title + description ~160 символов с УТП | `layout.tsx` | Нормальный сниппет в выдаче | ✅ |
| 1.2 | JSON-LD `Organization` + `WebSite` | `SiteJsonLd` в root layout | Понимание бренда поисковиком | ✅ |
| 1.3 | Секция **«С чем помогаем»** | `HomeHelpTopics` | Тематические ключи + ссылки | ✅ |
| 1.4 | Секция **«Готовые решения»** — до 6 free + CTA | `HomeSolutionsPreview` | Discovery + перелинковка | ✅ |
| 1.5 | Ссылки: тарифы → `/price`, форма → `/support` | `AttentionSection`, `QuestionForm`, `PriceSection` | Перелинковка | ✅ |

**Оценка:** 1–2 дня.  
**Риск:** низкий.

## Порядок секций на `/` (актуальный)

```text
1. Hero (TitleAnimate)
2. MainText (+ H2)
3. С чем помогаем
4. Готовые решения (превью)
5. Как это работает
6. Тарифы (PriceSection) → /price
7. Перед покупкой (Attention) → /price
8. База знаний (превью)
9. FAQ (+ FAQPage JSON-LD)
10. Мы (+ тизер О нас → /about)
11. Напишите нам (QuestionForm) → /support
```

## Вне скоупа (пока)

- Полноценный блог / новости
- Выдуманные отзывы и рейтинги
- Дублирование всей `/price` comparison table на главной
- Тяжёлый видео-hero без контентной отдачи

---

- [x] С главной есть кликабельные пути в `/problems`, `/instructions`, `/price`, `/about`, `/support`
