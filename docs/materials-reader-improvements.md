# План улучшения материалов

Ориентир: длинные «Готовые решения» и материалы в кабинете читаются как скролл без опор. Улучшения идут по слоям — навигация → метаданные → богаче контент → каталог/прогресс → визуал и комфорт чтения.

---

## Фаза 1 — Навигация (быстрый эффект) ✅

**Цель:** не теряться в длинном тексте и легко ходить между материалами.

| # | Задача | Где | Результат | Статус |
|---|--------|-----|-----------|--------|
| 1.1 | Якоря на `heading` / `subheading` (`id` из slug текста) | `MaterialContent` | Можно ссылаться на секции | ✅ |
| 1.2 | Оглавление: список секций под шапкой | reader pages + `MaterialToc` | Сканирование и прыжки | ✅ |
| 1.3 | Ссылка «Назад» на `/problems/[slug]` | `ProblemsPageContent` | Выход из материала | ✅ |
| 1.4 | Prev / Next в рамках списка «Готовые решения» и полки кабинета | problems + cabinet | Непрерывное чтение | ✅ |
| 1.5 | SEO-title = `material.title` (не slug) | `problems/[slug]/page.tsx` | Нормальные вкладки и шаринг | ✅ |

**Оценка:** 1–2 дня.  
**Риск:** низкий — только фронт, без смены модели блоков.

## Фаза 5 — Визуал и комфорт чтения

**Цель:** материал читается как спокойный длинный текст, а не как SaaS-карточка с одинаковым Inter на всём. Внешняя привлекательность + комфорт глаз без новых типов блоков и без бэка.

**Контекст:** фазы 1–4 закрыли опоры (TOC, прогресс, блоки). Сейчас слабость — типографика, ритм, cover и «сырые» list/quote/callout.

| # | Задача | Где | Результат | Статус |
|---|--------|-----|-----------|--------|
| 5.1 | Единая типографика reader: развести display (H1–H3) и body; line-height ~1.7–1.75; чуть более тёмный цвет абзаца | `MaterialContent` + shells (или общий `_reader-typography.scss`) | Текст не «выцветает», иерархия читается | ⬜ |
| 5.2 | Ритм вертикальных отступов: стабильные `margin` на стыках list→heading, quote→paragraph, image→text | `MaterialContent.module.scss` | Меньше рваности в длинных материалах | ⬜ |
| 5.3 | Cover не съедает первый экран: короче hero (напр. 21:9 / ниже `max-height`), мягкий fade в контент | problems / cabinet / instructions shells | Заголовок и старт текста ближе к fold | ⬜ |
| 5.4 | Shell ближе к «листу»: спокойный off-white фон страницы, меньше «карточной» тени/рамки (или ослабить) | reader shells | Immersive reading, меньше chrome | ⬜ |
| 5.5 | Доводка блоков: кастомные маркеры ul/ol; quote italic + чуть крупнее; callout с меткой («Важно») | `MaterialContent` | Сканируемость и «дорогой» вид без новых типов | ⬜ |
| 5.6 | Sticky TOC справа на desktop + подсветка текущей секции при скролле | `MaterialToc` + shell layout | Ориентир в длинных материалах | ⬜ |
| 5.7 | Первый абзац чуть крупнее/насыщеннее; H2 с лёгким визуальным якорем (линия или accent-bar) | `MaterialContent` | Вход в текст и главы | ⬜ |
| 5.8 | Prev/Next: заголовок в 2 строки + более читаемая стрелка/лейбл | `MaterialAdjacentNav` | Меньше «админских» карточек | ⬜ |

**Опционально в той же фазе (если останется время):**

| # | Задача | Результат |
|---|--------|-----------|
| 5.9 | Контроль кегля (A− / A+) или body 17–18px на mobile по умолчанию | Комфорт на телефоне |
| 5.10 | Прогресс привязан к `article`, не только fixed 3px у viewport | Ощущение «читаю документ» |

**Не входит:** dark mode ради галочки; видео; WYSIWYG; смена модели блоков.

**Оценка:** 2–3 дня.  
**Риск:** низкий — только фронт/CSS; желательно выровнять три оболочки (problems / cabinet / instructions), иначе правки дублируются.

**Зависимость:** частично пересекается с фазой 6.3 (общие стили типографики) — имеет смысл сделать 5.1 сразу как общий partial, чтобы не править три раза.

## Критерий готовности «удобно читать»

- В длинном материале есть оглавление и якоря
- Есть выход назад и переход к соседнему материалу
- Видны объём (минуты) и прогресс
- Можно оформить шаги списком и выделить важный тезис
- Есть каталог, шаринг и продолжение чтения с другого устройства (для вошедших)

**Критерий фазы 5 (визуал):**

- Body и заголовки визуально разведены; длинный текст не выглядит «серым Inter на белой карточке»
- Cover не выталкивает заголовок далеко ниже fold на mobile
- List / quote / callout выглядят осознанно оформленными
- На desktop оглавление доступно при скролле (sticky) с понятной текущей секцией
